# Proyecto Euler Python

## Descripción

Este proyecto reúne soluciones en Python a varios retos de [Project Euler](https://projecteuler.net/), una web con problemas de matemáticas y programación pensados para practicar el razonamiento lógico y la resolución de problemas.

El proyecto está diseñado de forma modular: cada problema se encuentra en su propia carpeta y es reutilizable tanto de manera independiente como desde un **menú principal**.

## Problemas incluidos

Hay ejercicios sobre múltiplos, sucesiones de Fibonacci, factores primos, números palíndromos, divisibilidad, ternas pitagóricas y sumas de números primos, entre otros. Cada carpeta contiene una solución independiente para uno de estos retos.
